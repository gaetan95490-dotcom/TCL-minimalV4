# Navigation à la télécommande — TCL Home

- Flèches gauche/droite/haut/bas : naviguer entre YouTube, Netflix, Prime Video, Disney+, HDMI, Réglages et Quitter.
- OK/Entrée : ouvrir le bouton sélectionné.
- Retour : comportement Android standard ; fermer les fenêtres de réglages.
- Le bouton actif est surligné en bleu avec un contour blanc et agrandi.
- Focus initial sur une application, et retour sur le dernier bouton sélectionné après un changement de réglage.

Pour mettre à jour GitHub : remplacer les fichiers du dépôt par ceux de cette archive, puis lancer Actions > Build TCL Home APK. L'APK n'a pas été compilé dans cet environnement ; tester les flèches et OK sur la TV.
